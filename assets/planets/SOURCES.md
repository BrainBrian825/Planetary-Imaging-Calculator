# Planet image sources

The preview uses locally bundled imagery from NASA and USGS mission archives.
For targets with a global map, the calculator projects that map onto the
calculated Earth-facing hemisphere and applies the selected-time phase and pole
orientation. Other source photos are rotated and phase-masked, but their
surface or cloud details remain tied to the date on which the source image was
captured.

Saturn’s ring texture is derived from Cassini’s natural-color
[A Full Sweep of Saturn’s Rings](https://science.nasa.gov/photojournal/a-full-sweep-of-saturns-rings/)
mosaic (NASA/JPL/Space Science Institute). The preview projects this radial
structure into the calculated opening angle and splits it into front and rear
layers around Saturn’s globe.

The OPAL Saturn, Uranus, and Neptune products are real 360-degree atmospheric
maps. They are archival cloud observations, not forecasts. Regions hidden from
Hubble by the planet’s viewing geometry, including Uranus’s southern latitudes
and Neptune’s northern cap, use a neutral continuation of the nearest measured
cloud color without invented storms. Saturn’s ring-obscured equatorial strip is
interpolated between the adjacent measured cloud bands. Saturn’s map has a
restrained warm color balance so its globe and Cassini natural-color ring
mosaic share the same cream, ochre, and muted-gold palette; the atmospheric
band structure is unchanged.

Neptune’s OPAL map uses a deeper cobalt-blue, Voyager-inspired color balance
for the familiar photographic appearance requested by the project. The
underlying cloud structure and contrast are preserved; the color treatment is
representational rather than a strict true-color reconstruction.

Jupiter’s central System III longitude is calculated for the selected time, but
the visible cloud texture comes from Cassini observations in December 2000.
Individual storms and cloud bands drift, so it is not a live Jovian weather
forecast.

The Sun uses an archival Carrington synoptic map as a 3D reference texture. Its
pole angle and central longitude are calculated for the selected instant, but
the rendered sunspots are not a forecast for that date.
